# АрендаЛог на Cloudflare Workers

Вариант сервера синхронизации для Cloudflare: тот же API, что у версии на Node.js, но без файловой
системы — метаданные и события в **KV**, вложения в **R2**.

Клиенту всё равно, где сервер: в разделе «Общий доступ» просто указывается адрес.

```
npm install -g wrangler
wrangler login
wrangler kv namespace create SPACES          # взять id и вписать в wrangler.toml
wrangler r2 bucket create arendalog-blobs
wrangler deploy
```

После `deploy` появится адрес вида `https://arendalog-sync.<аккаунт>.workers.dev` — его и нужно вписать
в приложении.

## Сколько это будет стоить

| Компонент | Бесплатный тариф | Что дальше |
|---|---|---|
| Workers (запросы) | 100 000 в сутки | $5/мес за 10 млн |
| KV (метаданные и события) | 1 ГБ, 100 000 чтений, **1 000 записей** в сутки | входит в $5 |
| R2 (фото и чеки) | **10 ГБ**, 1 млн записей и 10 млн чтений в месяц, исходящий трафик бесплатно | $0.015 за ГБ |
| Durable Objects | **только платно** | не используются в этой версии |

Прикидка для одного дома (≈50 МБ фото, 100 событий за 11 месяцев):

- запись события = 2 операции KV → 200 операций за всю аренду;
- фото = 2 МБ/мес в R2 → 50 МБ за аренду, это 0,5 % бесплатных 10 ГБ;
- запросов — сотни в месяц против 3 млн бесплатных.

**Вывод: для одного–двух объектов бесплатного тарифа хватает с запасом, платить не нужно.**
Если объектов станет больше сотни — 10 ГБ R2 закроют примерно 200 журналов, дальше $0.015/ГБ (копейки).

Для сравнения: дешёвый VPS под ту же задачу — 250–450 ₽/мес, но его надо обслуживать.
Cloudflare удобнее тем, что нечего администрировать, и он уже есть у вас.

## Отличия от версии на Node.js

| | Node.js | Cloudflare Workers |
|---|---|---|
| Хранилище событий | JSON-файл пространства | KV: отдельный ключ на событие |
| Вложения | файлы на диске | R2 |
| Реальное время | SSE мгновенно | SSE через опрос KV: задержка 1,5–3 с, соединение живёт 25 с и переподключается |
| Целостность | проверка хеша и цепочки на сервере | проверка хеша; цепочка проверяется на клиенте и в верификаторе |
| Лимит пространства | 500 МБ (настраивается) | ограничен квотой KV/R2 |
| Согласованность | строгая | eventual: запись видна в своём регионе сразу, в других — до 60 с |

## Ограничения, которые стоит учитывать

- **KV не для частых записей**: 1 000 записей в сутки на бесплатном тарифе — это ~500 событий в день,
  для бытового сценария огромный запас, но не для промышленной нагрузки.
- **Список событий** ограничен 1 000 ключей на пространство (`KV.list`). Для аренды это много,
  но при переполнении нужно перейти на индексирование в Durable Objects.
- **SSE через опрос** тратит чтения KV: 1 чтение в 1,5 с на подключённого зрителя. Три зрителя за сутки —
  это ~170 тысяч чтений, уже больше бесплатных 100 тысяч. Если планируете держать поток открытым
  постоянно, выгоднее Workers Paid или VPS.
- **Нет Durable Objects** — сознательно: они платные, а для одного-двух объектов хватает KV.

## Альтернатива, если баланс платить не хочется

Полностью бесплатный путь без Cloudflare: VPS из бесплатного тарифа Oracle Cloud (1–4 vCPU, до 24 ГБ)
и версия сервера на Node.js из папки `server/`. Или вообще без сервера — обмен файлами `.alog`
между арендатором и арендодателем.
